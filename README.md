# سیستم جامع امنیتی، دزدگیر هوشمند و نظارت تصویری کیارش (Kiarash Security Suite)

این ریپازیتوری شامل تمامی بخش‌های پروژه و فایل **GitHub Actions** (`.github/workflows/build-all.yml`) است که بدون نیاز به نصب هیچ کامپایلری روی سیستم شما، به صورت خودکار فایل اجرایی ویندوز (`.exe`) و فایل نصبی اندروید (`.apk` سازگار با اندروید 5.0.2 به بالا) را در بخش **Actions -> Artifacts** گیت‌هاب می‌سازد.

---

## ۱. نحوه دریافت خروجی از GitHub Actions (بدون کامپایلر)
1. تمام محتویات این پوشه را در یک Repository جدید در GitHub آپلود (Push) کنید.
2. وارد تب **Actions** در ریپازیتوری گیت‌هاب خود شوید.
3. ورک‌فلوی `Build Security System (Windows EXE + Android APK)` به صورت خودکار اجرا می‌شود و در پایان دو فایل خروجی زیر را به شما تحویل می‌دهد:
   - **`Windows-Security-Core-EXE`**: برنامه کامل ویندوز با هوش مصنوعی YOLOv8، ضد سایه، پنل وب ریموت و ارتباط با آردوینو.
   - **`Android5-Camera-Bridge-APK`**: برنامه مخصوص گوشی دوربین (اندروید 5.0.2) با قابلیت اتصال خودکار وای‌فای، اجرای خودکار در زمان روشن شدن، کار با صفحه خاموش (WakeLock)، استریم تصویر، تماس ترتیبی و دریافت پیامک `توقف آلارم` / `قطع هشدار`.

---

## ۲. راه‌اندازی دسترسی از راه دور بدون VPS و بدون IP استاتیک (Tailscale / Cloudflare)
برای اینکه از روی گوشی‌های ریموت (هم اندروید ۵ و هم اندروید ۱۶) از هر جای دنیا بدون نیاز به خرید VPS یا IP استاتیک به کامپیوتر مغازه وصل شوید:
- **روش اول (پیشنهادی - Tailscale):** برنامه رایگان Tailscale را روی ویندوز و گوشی نصب کنید. یک آی‌پی ثابت خصوصی به ویندوز می‌دهد که پنل وب روی پورت `8000` (مثلاً `http://100.x.y.z:8000`) همیشه در دسترس است.
- **روش دوم (بدون نصب اپ روی گوشی اندروید ۵ - Cloudflare Quick Tunnel):** فایل `cloudflared.exe` را کنار برنامه ویندوز بگذارید و دستور زیر را بزنید تا یک لینک اینترنتی مستقیم HTTPS به شما بدهد:
  ```bash
  cloudflared tunnel --url http://localhost:8000
  ```
  این لینک روی مرورگر قدیمی اندروید ۵ و مرورگر جدید اندروید ۱۶ با رابط کاربری زیبا باز می‌شود و پخش زنده، قطع آژیر، فعال/غیرفعال‌سازی دزدگیر و بازبینی ضبط‌های تاریخ شمسی را انجام می‌دهد.

---

## ۳. تنظیم روشن شدن خودکار کامپیوتر پس از قطع و وصل برق
1. در تنظیمات **BIOS** مادربرد کامپیوتر، به بخش `Power Management` یا `APM Configuration` بروید و گزینه **Restore on AC Power Loss** را روی **Power On** قرار دهید.
2. در ویندوز، دستور `netplwiz` را در Run بزنید و تیک رمز عبور در زمان بالا آمدن ویندوز را بردارید تا مستقیم وارد دسکتاپ شود.
3. فایل `windows_core/setup_autostart.bat` را یک بار اجرا کنید تا هم Sleep ویندوز غیرفعال شود و هم برنامه به Startup ویندوز اضافه گردد.
